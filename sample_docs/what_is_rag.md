# 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与文本生成相结合的技术，用于提升大语言模型（LLM）的回答质量。

## RAG 的核心原理

传统的大语言模型（如 GPT）在训练后参数固定，无法获取训练数据之外的新知识，且容易产生"幻觉"（生成看似合理但实际错误的内容）。RAG 通过以下步骤解决这个问题：

1. **检索阶段**：根据用户的查询，从外部知识库中检索相关的文档片段
2. **增强阶段**：将检索到的相关信息与用户查询组合成提示词
3. **生成阶段**：让大语言模型基于增强后的上下文生成回答

## RAG 的优势

- **知识实时更新**：无需重新训练模型，只需更新知识库即可获取最新信息
- **减少幻觉**：所有回答都基于检索到的真实文档，可追溯来源
- **成本可控**：相比微调模型，RAG 方案实施成本更低
- **可解释性强**：可以通过引用的文档片段验证回答的准确性

## RAG 的典型应用场景

- **企业内部知识库问答**：让员工能够自然语言查询企业文档
- **客服机器人**：基于产品手册自动回答用户问题
- **法律文档分析**：从合同、法规等文档中快速检索信息
- **医疗辅助**：基于医学文献提供参考建议
- **教育领域**：基于教材和资料提供个性化学习辅导
