FAISS 简介

FAISS（Facebook AI Similarity Search）是 Facebook 开发的一个开源库，专门用于高效的向量相似度搜索和密集向量聚类。

FAISS 的核心特性

1. 高效的相似度搜索：能够在数十亿级别的向量中快速找到最相似的向量
2. 多种索引类型：
   - IndexFlatL2：精确搜索，计算查询向量与所有向量的 L2 距离
   - IndexIVFFlat：倒排文件索引，通过聚类加速搜索（近似搜索）
   - IndexPQ：乘积量化索引，大幅减少内存占用
   - IndexIVFPQ：倒排文件 + 乘积量化，平衡速度和精度

3. GPU 加速支持：可以利用 NVIDIA GPU 进行并行计算
4. 内存优化：通过各种量化技术减少向量的内存占用

向量相似度计算方法

FAISS 主要支持以下相似度计算方式：

- L2 距离（欧氏距离）：计算两个向量之间的直线距离
- 内积（Inner Product）：计算两个向量的点积，适用于已归一化的向量
- 余弦相似度：内积除以两个向量的模长乘积

RAG 中的 FAISS 应用

在 RAG 系统中，FAISS 通常用于以下环节：

1. 索引构建阶段：将所有文档的向量表示存储到 FAISS 索引中
2. 检索阶段：根据查询向量，在 FAISS 索引中快速找到最相似的 top-k 个文档向量

典型使用流程：

1. 将所有文档 chunk 向量化（使用 Embedding 模型）
2. 使用 FAISS 创建索引并添加所有向量
3. 保存索引到磁盘，供后续查询使用
4. 查询时，将问题向量化，使用 FAISS 搜索相似向量
5. 根据搜索到的向量 ID，获取对应的文档内容

FAISS 的优势

- 速度快：优化的 C++ 实现，比纯 Python 实现快数十倍
- 可扩展性好：支持单机和分布式部署
- 成熟稳定：由 Facebook 维护，广泛应用于生产环境
- 功能丰富：提供多种索引类型和相似度计算方法
